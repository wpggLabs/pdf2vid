What it does

📄 Real PDF parsing

Text extraction, page thumbnails, scene selection, and editable per-scene scripts.

🗣️ Read-along captions

Captions follow the narration line by line — word-accurate with edge-tts subtitles.

🎬 Premium render

Blurred graded backdrop (no black bars), Ken Burns motion, vignette, drop-shadow captions.

🎙️ Many voices

edge-tts, Kokoro, and Chatterbox locally; OpenAI & ElevenLabs with your own key.

🌍 Offline translation

Argos translates on-device; OpenAI / Google Cloud optional.

🔒 Private by design

API keys in the OS keyring, no telemetry, fully offline once local models are installed.

How it works

Import a PDF. Each page becomes a scene with a page image and an editable narration script.
Pick language & voice. Free defaults work with no setup; add a local model or an API key for higher quality.
Export. pdf2vid narrates each scene, syncs read-along captions, and renders 1920×1080 (YouTube) and 1080×1920 (TikTok).

pdf2vid is a native desktop app — the rendering (FFmpeg) and voice pipelines run locally on your machine, so there is no in-browser version. FFmpeg is bundled; the free defaults need nothing else installed.

Built with Tauri 2, React 19, Rust, pdfjs-dist, FFmpeg, edge-tts, Kokoro, Chatterbox, and Argos Translate.
